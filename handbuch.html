Quizzer Handbuch

Jeopardy-ähnliches Quiz-Spiel für Windows. Der Spielleiter steuert das Spiel am PC — Spieler buzzen über ihr Smartphone.

.NET 10 / WPF SignalR Buzzer SQL Server 4 Fragetypen

📋 Übersicht

Quizzer ist eine Desktop-Anwendung für Windows, die ein Jeopardy-ähnliches Quiz ermöglicht. Das Spielfeld besteht aus einem konfigurierbaren Grid aus Kategorien und Punktewerten. Spieler verbinden sich über ihren Smartphone-Browser mit dem eingebauten Buzzer-Server und können in Echtzeit buzzen.

🖥️

Spielleiter-PC

Steuert das gesamte Spiel über die WPF-Anwendung.

📱

Spieler-Smartphones

Verbinden sich per Browser & QR-Code mit dem Buzzer.

📺

Publikums-Bildschirm

Optionaler zweiter Monitor zeigt das Spielfeld für alle.

🗄️

Datenbank

SQL Server LocalDB speichert Spiele, Fragen & Ergebnisse.

⚙️ Voraussetzungen

KomponenteAnforderung
BetriebssystemWindows 10 / 11 (64-bit)
Laufzeit.NET 10 Runtime (Windows Desktop)
DatenbankSQL Server LocalDB (wird mit Visual Studio / SQL Server Express installiert)
NetzwerkWLAN-Netzwerk, dem alle Spieler-Smartphones beitreten können
Spieler-GerätJeder moderne Browser (Chrome, Safari, Firefox)
⚠️
Der Buzzer-Server verwendet einen lokalen Port (Standard: 5000). Stelle sicher, dass die Windows-Firewall eingehende Verbindungen auf diesem Port erlaubt, damit Smartphones sich verbinden können.

🚀 Erste Schritte

1. Asset-Ordner anlegen

Quizzer benötigt einen Ordner mit Hintergrundbildern. Lege den Ordner an und befülle ihn mit den benötigten Bilddateien:

E:\QuizzerData\
  ├── Background.png
  ├── CellBackground.png
  ├── CellBackgroundHover.png
  ├── CellBackgroundIsDone.png
  ├── GridBackground.png
  ├── GridBackgroundResult.png
  ├── HorizontalBackground.png
  ├── HeaderColumnBackground.png
  ├── HeaderRowBackground.png
  ├── PlaceholderPlayer.png
  ├── PlayerCardBackground.png
  ├── PlayerCardBackgroundWinner.png
  ├── AudioPlaceholderFile.png
  └── Resources\          ← Fragen-Medien (Bilder, Videos, Audio)
ℹ️
Der Pfad zum Asset-Ordner wird in appsettings.json unter AppSettings:FilePathQuizzer konfiguriert. Der Standardpfad ist E:\QuizzerData.

2. Datenbank initialisieren

Beim ersten Start legt Quizzer die Datenbank automatisch an. Falls du die Migrationen manuell ausführen möchtest:

dotnet ef database update --project Quizzer.Logic --startup-project Quizzer.EF

3. Anwendung starten

Starte Quizzer.exe oder über Visual Studio mit F5. Die Hauptansicht zeigt eine Liste aller gespeicherten Spiele.

🎮 Spiel erstellen

Ein Spiel (Game) definiert das Spielfeld-Grid, die Spieler, die Punkte-Multiplikatoren und die Phasen-Einstellungen.

1

Neues Spiel anlegen

Klicke in der Spielliste auf Neu. Vergib einen Namen (Designation) und konfiguriere Breite (Spalten) und Höhe (Zeilen) des Grids.

2

Grid-Größe festlegen

Breite = Anzahl der Kategorien (Spalten), Höhe = Anzahl der Schwierigkeitsgrade (Zeilen). Standard: 5×5.

3

Multiplikatoren konfigurieren

Stelle DifficultyMultiplier, PhaseMultiplier und die zugehörigen Additions-Werte ein. Diese beeinflussen die Endpunkte jeder Zelle.

4

Moderator festlegen

Weise dem Spiel einen Moderator-Spieler zu. Der Moderator steuert den Spielfluss, sammelt aber keine Punkte.

5

Spiel speichern

Klicke auf Speichern. Das Spiel befindet sich nun im Status Building.

🏷️ Kategorien

Kategorien sind die thematischen Gruppen, denen Fragen zugeordnet werden. Sie erscheinen als Spalten-Überschriften im Spielfeld.

1

Kategorienverwaltung öffnen

Navigiere über das Hauptmenü zu Kategorien.

2

Neue Kategorie anlegen

Klicke auf Neu und vergib einen Namen, z.B. "Geschichte", "Sport" oder "Wissenschaft".

3

Im Spiel zuweisen

Beim Aufbau des Spielfelds wählst du für jede Spalte eine Kategorie als Header aus.

💡
Kategorien sind spielübergreifend — du kannst dieselbe Kategorie in mehreren Spielen verwenden.

❓ Fragen anlegen

Jede Frage besteht aus einem oder mehreren Schritten (QuestionStepResources). Schritte können Text, Bilder, Videos oder Audio enthalten und werden nacheinander aufgedeckt.

Grundfelder einer Frage

FeldBedeutung
DesignationVollständiger Name der Frage (intern)
DesignationShortKurz-Bezeichnung, die im Spielfeld-Grid angezeigt wird
QuestionTextOptionaler Fragetext (alternativ kann der Text im ersten Schritt stehen)
KategorieThematische Zuordnung
PunkteBasis-Punktewert (wird durch Multiplikatoren skaliert)
MinusPunkteAbzug bei falscher Antwort
SchwierigkeitLevel 0–15 (fließt in die Punkteberechnung ein)
NotizenInterne Anmerkungen des Spielleiters (für Spieler nicht sichtbar)

Schritte einer Frage

Die Schritte werden in dieser Reihenfolge abgespielt:

→

Start-Schritt

Optionales Intro der Frage. Im Schritt-Dialog über Ist Startschritt gesetzt, höchstens einer je Frage, ohne Anzeige-Schlüssel. Ohne Intro beginnt die Frage direkt mit dem ersten Hinweis.

A

Normale Schritte

Hinweise, Antwort-Optionen oder Teilfragen. Werden alphabetisch (A, B, C…) oder numerisch (1, 2, 3…) beschriftet. Reihenfolge kann zufällig gemischt werden.

✓

Finish-Schritt

Zeigt die Auflösung und läuft immer zuletzt. Je Frage ist höchstens ein Abschluss-Schritt erlaubt.

Ressourcen zu Schritten hinzufügen

Jedem Schritt kann eine Mediendatei beigefügt werden. Dateien werden im Ordner E:\QuizzerData\Resources\ abgelegt. Unterstützte Typen:

Bild

PNG, JPG, …

🎬

Video

MP4, …

🎵

Audio

MP3, WAV, …

📄

PDF, …

🃏 Fragetypen

Quizzer unterstützt vier Fragetypen, die jeweils unterschiedliche Spielmechaniken und Buzzer-Layouts verwenden:

Typ Buzzer-Layout Besonderheit
Standard Buzzer Klassisch: erster Spieler der buzzt, darf antworten. Schritte in fixer Reihenfolge.
Multiple Choice KeySelect Spieler wählen eine Antwort-Taste. Optionen werden zufällig gemischt, im Grid angezeigt.
Eigenschaften Buzzer Hinweise werden schrittweise aufgedeckt. Punkte sinken proportional mit jedem Schritt.
Schätzfrage Texteingabe Der Autor legt fest, was geschätzt wird (Zahl, Prozent, Länge, Masse, Volumen, Dauer, Datum, Geldbetrag) und in welcher Einheit. Die Spieler tippen einen Wert; wer am nächsten dran liegt, wird automatisch als Gewinner vorgeschlagen. Bei Gleichstand gewinnen alle Gleichauf-Spieler. Der Spielleiter kann jede Bewertung ändern.
💡
Der Fragetyp bestimmt automatisch das passende Buzzer-Layout, den Anzeigemodus und andere Standardwerte — du musst diese nicht manuell setzen.

🗺️ Spielfeld aufbauen

Im Bearbeitungs-Modus (Building) weist du jeder Zelle des Grids eine Frage zu.

1

Header definieren

Weise jeder Spalte eine Kategorie als Überschrift zu, und vergib jeder Zeile einen Namen (z.B. "100 Punkte", "200 Punkte").

2

Fragen zuweisen

Klicke auf eine Zelle im Grid und wähle die gewünschte Frage aus dem Fragenkatalog. Die Zelle zeigt dann die Kurz-Bezeichnung der Frage.

3

Punkte prüfen

Die berechneten Punkte jeder Zelle werden automatisch aus Basis-Punkten, Schwierigkeit und Phasen-Multiplikatoren ermittelt.

ℹ️
Zellen können auch leer bleiben — leere Zellen werden im Spiel als inaktiv dargestellt und können nicht angeklickt werden.

👥 Spieler verwalten

Spieler werden einmalig angelegt und können danach in beliebig vielen Spielen verwendet werden.

Spieler anlegen

1

Spielerverwaltung öffnen

Navigiere zu Spieler im Hauptmenü.

2

Neuen Spieler anlegen

Klicke auf Neu. Vergib einen internen Namen (Designation) und einen optionalen Anzeigenamen (DisplayName). Wenn DisplayName leer ist, wird Designation angezeigt.

3

Profilbild zuweisen (optional)

Lege ein Profilbild im Asset-Ordner ab und trage den Dateinamen beim Spieler ein.

Spieler zum Spiel hinzufügen

Öffne das Spiel in der Bearbeitungsansicht und füge Spieler über den Bereich Spieler hinzu. Vergiss nicht, einen Spieler als Moderator zu definieren — der Moderator ist Pflicht, damit das Spiel gestartet werden kann.

⚠️
Ein Spiel kann nicht gestartet werden, wenn kein Moderator festgelegt ist oder wenn keine Spieler hinzugefügt wurden.

📡 Buzzer-Server

Der eingebaute Kestrel/SignalR-Server ermöglicht es Spielern, sich per Smartphone zu verbinden und in Echtzeit zu buzzen.

Server starten

1

Buzzer-Server öffnen

Klicke während des laufenden Spiels auf Buzzer-Server. Ein Fenster öffnet sich mit Server-Status und QR-Code.

2

Server starten

Klicke auf Server starten. Der Server läuft dann auf deiner lokalen IP-Adresse (z.B. http://192.168.1.100:5000).

3

QR-Code teilen

Zeige den QR-Code den Spielern — jeder scannt ihn mit seinem Smartphone und wird automatisch verbunden.

4

Verbindungen prüfen

Das Buzzer-Server-Fenster zeigt an, welche Spieler verbunden sind (grün) und welche nicht (grau).

ℹ️
Spieler-IDs sind GUIDs — jeder Spieler hat eine feste ID und kann sich bei Verbindungsverlust einfach neu verbinden, ohne seinen Fortschritt zu verlieren.
⚠️
Spielleiter-PC und Spieler-Smartphones müssen sich im selben WLAN-Netzwerk befinden.

▶️ Spiel spielen

Spiel starten

1

Spiel auswählen & starten

Wähle das Spiel in der Liste und klicke auf Spielen. Das Spiel wechselt in den Status InProgress.

2

Spieler-Ansicht öffnen (optional)

Klicke auf Spieler-Ansicht öffnen, um einen zweiten Monitor für das Publikum zu aktivieren.

3

Frage auswählen

Der aktuelle Auswahl-Spieler (ChoosingPlayer) wählt eine Zelle aus dem Grid. Klicke im Spielleiter-Fenster auf die gewünschte Zelle.

4

Frage spielen

Das Fragen-Fenster öffnet sich. Klicke auf Weiter, um Schritt für Schritt die Hinweise aufzudecken. Spieler buzzen über ihr Smartphone.

5

Antwort bewerten

Nach dem Buzzen bewertest du die Antwort als Richtig oder Falsch. Punkte werden automatisch vergeben oder abgezogen.

6

Nächste Frage

Die gespielte Zelle wird als Erledigt markiert. Der nächste Auswahl-Spieler wird automatisch bestimmt (Gewinner oder Round-Robin).

Vollbild-Modus

Klicke auf Vollbild, um alle geöffneten Spielfenster in den Vollbild-Modus zu schalten. Ideal für die Präsentation auf einem Beamer oder TV.

⚡ Phasen & Schwierigkeit

Spielphasen

Ein Spiel kann in mehrere Phasen unterteilt werden. In späteren Phasen sind die Punkte höher (durch den Phase-Multiplikator). Beim Erreichen eines Schwellenwerts (PhaseTrashholds) fragt das Spiel automatisch, ob zur nächsten Phase gewechselt werden soll.

EinstellungBedeutung
SuggestedPhasesEmpfohlene Anzahl an Phasen (bestimmt die Schwellenwerte)
PhaseMultiplierMultiplikator pro Phase (Standard: 1 = keine Erhöhung)
PhaseAdditionFixer Additionswert pro Phase

Du kannst die Phase auch manuell mit den Schaltflächen Phase + und Phase − im Spielleiter-Fenster ändern.

Schwierigkeitsgrade

Jede Frage hat einen Schwierigkeitsgrad (Level 0–15), der die Punkte skaliert.

🏆 Punktesystem

Die Punkte einer Spielfeld-Zelle werden nach folgender Formel berechnet:

Punkte = ( QuestionBase.Points × (DifficultyMultiplier × (int)Difficulty + 1)
         + DifficultyAddition × (int)Difficulty )
         × ( PhaseMultiplier × Phase ) + PhaseAddition × Phase

Ergebnis eines Spielers

WertBerechnung
ScoreSumme aller erzielten Punkte
MinusScoreSumme aller Minuspunkte (Falschantworten)
CorrectionManuelle Korrektur durch den Spielleiter
FinalScoreScore + Correction − MinusScore

Auswahl-Spieler

Nach jeder Frage wird der nächste Auswahl-Spieler bestimmt:

  • Wenn ein Spieler die Frage richtig beantwortet hat → dieser Spieler darf als nächstes wählen.
  • Wenn niemand richtig lag → Round-Robin, der nächste Spieler in der Liste.

📱 Verbinden & Buzzen (Spieler)

1

QR-Code scannen

Der Spielleiter zeigt einen QR-Code auf seinem Bildschirm. Scanne ihn mit deiner Smartphone-Kamera oder einer QR-App.

2

Browser öffnet automatisch

Die Buzzer-Seite öffnet sich in deinem Browser. Du siehst deinen Namen und den aktuellen Rundenstand.

3

Warten auf Freigabe

Der Buzzer ist gesperrt, bis der Spielleiter die Frage freigibt. Sobald er aktiv ist, leuchtet die Taste auf.

4

Buzzen!

Drücke die Buzzer-Taste so schnell wie möglich. Nach dem ersten Buzz werden alle anderen Spieler gesperrt.

💡
Falls die Verbindung abbricht, lade die Seite neu — dein Spieler-Link bleibt gültig und du wirst automatisch wieder verbunden.

🔴

🔡

    "FilePathQuizzer": "E:\\QuizzerData",

🙋 FAQ

Spieler können sich nicht verbinden

Stelle sicher, dass sich alle Geräte im gleichen WLAN befinden und die Windows-Firewall eingehende Verbindungen auf dem Buzzer-Port (Standard: 5000) erlaubt. Füge ggf. eine Firewall-Ausnahme für Quizzer.exe hinzu.

Die App startet nicht / stürzt sofort ab

Überprüfe ob der Asset-Ordner (E:\QuizzerData) existiert und ob appsettings.json die korrekten Pfade enthält. Fehlt die Datenbank, führe die EF-Migrationen aus.

Ich möchte ein abgeschlossenes Spiel nochmals spielen

Setze in der Spiel-Bearbeitungsansicht das Flag Restart auf true und starte das Spiel. Beim nächsten Start werden alle Ergebnisse zurückgesetzt.

Kann ich Fragen aus einem Spiel in einem anderen verwenden?

Ja. Fragen sind unabhängig von Spielen gespeichert und können jederzeit in mehreren Spielen dem Grid zugewiesen werden.

Wie viele Spieler sind möglich?

Es gibt keine feste Obergrenze. Das System ist auf typische Quiz-Gruppen ausgelegt (3–10 Spieler). Bei sehr vielen Spielern kann die Anzeige auf dem Spielleiter-Bildschirm enger werden.

Kann ich das Spiel pausieren?

Es gibt keine explizite Pausieren-Funktion. Du kannst das Fragen-Fenster einfach offenlassen und zu einem beliebigen Zeitpunkt weitermachen.
